# Построение и анализ мета-мнений в социальных сетях на основе LLM-агентов и модальной логики

## Использование


## Формальная основа

### Модальная логика KD45

Используется система **KD45** для моделирования убеждений:

- **K**: Распределительная аксиома
- **D**: Серийность (каждый мир имеет хотя бы один достижимый)
- **4**: Транзитивность
- **E**: Евклидовость

Формулы имеют вид:
```
φ ::= p | ¬φ | B_i φ
```

где `B_i` — оператор веры агента `i`.

### Модель Крипке

Модель `M = (W, {R_i}_{i∈A}, V)` состоит из:
- `W` — множество возможных миров
- `R_i ⊆ W × W` — отношение достижимости для агента `i`
- `V` — функция оценки атомарных пропозиций

### Бисимуляционное сокращение

Для уменьшения размера моделей применяется классический алгоритм бисимуляционного quotient, который:
1. Разбивает миры на классы эквивалентности по оценке атомарных пропозиций
2. Итеративно уточняет разбиение по сигналам достижимости
3. Строит фактор-модель с сохранением модальной эквивалентности

## Метрики оценки

Для извлечения формул вычисляются:

- **Agents F1** — точность/полнота по списку агентов
- **Prop F1** — точность/полнота по атомарным пропозициям (с fuzzy matching через sentence-transformers)
- **Formulas F1 (tree)** — точное сопоставление структур формул
- **Formulas F1 (heuristic)** — эвристическое сопоставление по множествам
- **Formulas Exact Match** — полное совпадение множества формул
- **Depth Accuracy** — точность по глубине вложенности
- **Depth MAE** — средняя абсолютная ошибка по глубине

## Данные

### Синтетический бенчмарк Meta-Opinion

Каждый сэмпл содержит:
- `id` — уникальный идентификатор
- `topic` — тема диалога
- `text` — естественный диалог между агентами
- `agents` — список участников
- `propositions` — извлеченные атомарные утверждения
- `formulas` — модальные формулы с вложенными убеждениями
- `depth` — максимальная глубина вложенности

Датасеты различаются по разнообразию профилей и уровню шума (ирония, сарказм).

### Логи игры «Мафия»

- `game.jsonl` — события игры, роли, публичные сообщения
- `introspection.jsonl` — приватные ответы агентов о своих и чужих убеждениях

## Примеры

### Пример сэмпла датасета

```json
{
  "id": "abc123...",
  "topic": "Криптовалютная регуляция",
  "text": "Алиса: Криптовалюты нужно регулировать.\nБоб: Я думаю, Алиса права.",
  "agents": ["Алиса", "Боб"],
  "propositions": ["Криптовалюты нужно регулировать"],
  "formulas": [
    "B_Алиса(p1)",
    "B_Боб(B_Алиса(p1))"
  ],
  "depth": 2
}
```

### Пример формулы

- `B_Алиса(p1)` — Алиса верит, что p1
- `B_Боб(B_Алиса(p1))` — Боб верит, что Алиса верит, что p1 (мета-мнение первого порядка)
- `B_Боб(B_Алиса(B_Вася(p1)))` — мета-мнение второго порядка

## Научная новизна

Работа объединяет:
1. **Генерацию синтетических данных** — первый специализированный бенчмарк для мета-мнений
2. **Формальную семантику** — KD45-модели Крипке для представления вложенных убеждений
3. **Пайплайн обработки** — от текста к формальным структурам с бисимуляционным сокращением

## Результаты

В ходе экспериментов было протестировано более 8 LLM моделей (llama3.1, gpt-oss и др.). Ключевые наблюдения:

- Основная сложность — извлечение **структуры** вложенных убеждений, а не семантики
- Метрики по пропозициям (Prop F1) высокие (~0.9+), по формулам (Formulas F1 tree) ниже (~0.6-0.7)
- Разрыв между tree- и heuristic-оценкой указывает на ошибки в точной вложенности
- Более сильные reasoning-модели показывают лучший результат по Depth Accuracy
